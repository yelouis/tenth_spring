# Tenth Spring Places Pack Notice

`places_pack_v1.json.gz` is a derived database of OpenStreetMap data covering Tenth Spring's 87 public famous places (27 cities and 60 parks and wonders) from the `2026-10-01` OpenStreetMap snapshot.
